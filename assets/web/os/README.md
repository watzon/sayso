# Operating system logos

The download page shows these logos on the system buttons.

- `apple.svg` and `linux.svg` come from [Simple Icons](https://simpleicons.org) (CC0). The path data is unchanged.
- `windows.svg` is drawn here: four squares.

The files are in the public domain, but each logo is a trademark of its owner. Use them only to name the system that a download is for.
