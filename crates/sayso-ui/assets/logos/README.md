# Provider logos

The marks of the AI providers that Sayso works with. Sayso shows a mark only
to name its provider. Each mark belongs to its owner and is not covered by the
license of this crate.

- The SVG files come from LobeHub Icons (https://github.com/lobehub/lobe-icons,
  MIT), with the title and the inline style removed. One-color marks are drawn
  as tinted icons, so they follow the theme.
- `superwhisper.png` is the app icon on superwhisper.com, scaled to 128 px.
- `spokenly.png` is the app icon on spokenly.app (128 px).
